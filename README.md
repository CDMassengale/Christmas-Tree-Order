# Christmas Tree Order System

## Description
The Christmas Tree Order System is a JavaScript desktop application that allows users to place a Christmas tree order through a graphical user interface where users can select from three different Christmas tree options and choose between pickup or local delivery. The application dynamically updates the order summary based on the user's selections.

## Tools and Languages
- **JGrasp:** Development Environment to develop the application.
- **JavaScript:** Main programming language.
- **Java Swing:** Used to create the graphical user interface.
- **AWT (Abstract Window Toolkit):** Used for layout management and handling events.
- **ActionListeners:** Used to detect checkbox selections and update the order summary.

## Features
- **Tree Selection:** Choose between three Christmas trees:
  - Noble Fir ($199.00)
  - Nordmann Fir ($150.00)
  - Balsam Hill Fir ($400.00)
- **Delivery Options:** Select either pickup ($50.00) or local delivery ($120.00).
- **Order Summary:** Displays the selected tree and delivery option in a text field.
- **Interactive GUI:** Automatically updates the order summary when selections change.
- **Selection Restrictions:** Uses Java ButtonGroup to allow only one tree selection at a time.

## What I Built
I developed a graphical Christmas tree ordering application using Java Swing. The application provides an interactive interface where users can select a Christmas tree and a delivery method. I implemented event listeners to detect user selections and update the order summary dynamically.
